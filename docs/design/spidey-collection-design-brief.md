# SPIDEY SHELF — дизайн-бриф для Claude Design

Персональный трекер коллекции Funko Pop (серия Spider-Man). Владелец — Илья, коллекционирует
паучков в путешествиях; сайт публичный, чтобы друзья перед покупкой подарка могли проверить,
есть ли уже такая фигурка. **Mobile-first: 90% посещений — с телефона.** Десктоп — вторичен,
но должен быть проработан.

Рабочее название: **SPIDEY SHELF** (варианты: WEB SHELF, SPIDEY VAULT — можно предложить своё).

---

## 1. Настроение и референс

Референс — «Spidey Tracker» Неда из фильма Spider-Man: Brand New Day (скриншоты приложены
отдельно): ретро-футуристичный **пиксель-арт интерфейс самодельного гаджета** — как будто
трекер спаян школьником-гением из Nintendo, рации и картографического терминала.

Ключевые черты референса, которые переносим:

- Тёмно-синяя картографическая подложка с сеткой и тонкими линиями-меридианами
- Пиксельные маркеры-пауки в круглых рамках: **зелёные и красные** — у нас это
  «в коллекции» / «в вишлисте»
- Жирные пиксельные рамки-бордюры вокруг всего: экран как корпус гаджета
- LCD-дисплей с зелёным свечением и моноширинными цифрами (`0x00000000`) — для счётчиков
- Янтарно-жёлтые «резиновые» кнопки с чёрным пиксельным текстом (TERRAIN / CHAT / SHARE)
- Зелёные кнопки-профили, коралловые баннеры-плашки с «зубчиками»
- Бегущая строка (ticker) внизу: `UR SPIDEY SIGHTINGS ON X · SHARE YOUR…`
- Паутина-радар в углу карты
- Пиксельный спрайт Спайди как маскот в углу
- Плашка-уведомление «SIGHTING IN YOUR DIRECT VICINITY» с глазами Спайди сверху

Тон: игрушечный, тёплый, «сделано руками с любовью», но НЕ детский. Это гаджет, а не игра.

**Важно (юридическое):** не копировать кадры фильма один-в-один, не использовать логотипы
Marvel/Sony/Samsung и постерный леттеринг «Spider-Man». Вдохновляемся языком — пиксельный
гаджет-трекер — а не воспроизводим экран из фильма.

## 3. Типографика

- **Дисплейная / кнопки / счётчики:** пиксельный шрифт — Press Start 2P (есть кириллица)
  или Silkscreen. Только для коротких надписей: заголовки, кнопки, бейджи, цифры.
- **Основной текст (истории фигурок, описания):** читаемый гуманистический гротеск
  (Inter / system-ui). Пиксельным шрифтом длинные абзацы НЕ набирать.
- **LCD-цифры:** моноширинный с табличными цифрами, letter-spacing пошире.
- Язык интерфейса: английский (короткие слова лучше живут в пиксельном шрифте:
  OWNED / WANTED / SIGHTING), истории фигурок — на любом языке.

## 4. Структура: карта экранов

```
ПУБЛИЧНОЕ (без входа)
├── 1. Home — коллекция (грид) + счётчик + новинки
├── 2. Search — «есть ли у Ильи?» (главная фича для друзей)
├── 3. Figure page — фигурка: бокс-арт, история, где куплена
├── 4. Wishlist — чего не хватает (страница для дарителей)
└── 5. Stats + Travel Map — прогресс и карта покупок-«sightings»

АДМИНКА (только владелец, вход по паролю)
├── 6. Login — терминал гаджета
├── 7. Quick Add — скан штрих-кода → подтверждение → детали → готово
└── 8. Catalog — управление справочником фигурок
```

Порядок сборки макетов: 1 → 2 → 7 (три ключевых экрана), потом остальные.

## 5. Публичные экраны (mobile-first)

### 5.1 Home — коллекция

- Шапка-«корпус»: логотип SPIDEY SHELF пиксельным шрифтом + маскот-паучок
- **LCD-счётчик как герой экрана:** `12 / 117` с подписью `SPIDEY CANON COLLECTED`
  и тонким прогресс-баром-паутиной. Тап по счётчику → Stats
- Блок NEW SIGHTINGS: горизонтальная лента последних поступлений (карточки крупнее)
- Грид фигурок: 2 колонки на мобиле. Карточка = пиксельная рамка, бокс-арт на
  `--navy-panel`, номер фигурки на янтарном бейдже (`#1450`), имя, флаг страны покупки
- Табы-фильтры в стиле зелёных кнопок: `ALL SPIDERS` / `OTHER FIGURES`
- Бегущая строка внизу: `LATEST SIGHTING: SPIDER-MAN #1450 · LOS ANGELES · APR 2025`
- Прилипшая кнопка поиска (лупа в паутине) — всегда в зоне большого пальца

### 5.2 Search — главная фича для друзей

Сценарий: друг стоит в магазине с фигуркой в руках и проверяет, можно ли дарить.

- Одно огромное поле ввода: `ENTER POP NUMBER OR NAME…`, автофокус, цифровая клавиатура
  при вводе числа
- Результат — карточка с вердиктом-штампом на весь экран, видно без прокрутки:
  - **зелёный штамп `OWNED` + пиксельный паук в зелёной рамке** — «уже есть, ищи другую»
  - **коралловый штамп `NOT OWNED YET` + кнопка `→ IT'S A GIFT IDEA!`** — самый горячий
    момент сайта, ведёт на карточку в вишлисте
- Если номер делят несколько вариантов (chase, GITD, эксклюзивы) — список вариантов
  с мини-карточками, у каждого свой вердикт
- Результат шарится ссылкой `/search?q=1450`; состояние результата — отдельный экран макета
- Пустой результат: «не нашли в справочнике» + мягкий CTA написать владельцу

### 5.3 Figure page — страница фигурки

- Крупный бокс-арт в пиксельной рамке-«витрине», номер на янтарной плашке
- Статус: `OWNED` / `WANTED` / `NOT MINE ANYMORE` (серый)
- Блок SIGHTING LOG — история приобретения как запись в бортжурнале:
  флаг + город, дата LCD-цифрами, текст истории (обычным шрифтом)
- Мини-карта с пиксельным маркером города покупки
- Метаданные: линейка, год, эксклюзивность, варианты
- Навигация свайпом на соседние фигурки (← prev / next →)

### 5.4 Wishlist — для дарителей

- Заголовок-плашка с зубчиками: `WANTED: 105 SPIDERS STILL OUT THERE`
- Грид как на Home, но карточки с коралловой рамкой и штампом `WANTED`
- Сортировка-табы: `EASY TO FIND` / `RARE` / `ALL`
- У каждой карточки кнопка `SHARE` — отправить другу ссылку «подари мне вот эту»

### 5.5 Stats + Travel Map

- Паутина-радар как круговая диаграмма прогресса (референс: радар из фильма):
  сектора — линейки (Marvel / Movies / Gamerverse / Spider-Verse…), заполнение — % собранного
- Два LCD-счётчика: `CORE CANON 12/117` и `FULL SPIDER-VERSE 12/~400`
- **Карта мира как в референсе:** тёмно-синяя, пиксельные маркеры-пауки в городах покупок
  (Haifa, Munich, Tbilisi, Madrid, Amsterdam, Batumi, LA, Moscow, Mallorca…).
  Тап по маркеру → плашка «SIGHTING» со списком фигурок из этого города
- Таймлайн поступлений по годам (2023 → 2026)

## 6. Админка (только владелец)

### 6.1 Login

Экран-терминал: LCD-поле пароля, пиксельная клавиатура-подсказка, маскот. Одна кнопка `BOOT`.

### 6.2 Quick Add — сердце продукта. Цель: два тапа + скан

Шаги (каждый — отдельный фрейм макета):

1. **Идентификация.** Кнопка `⌖ SCAN BARCODE` (открывает камеру) + поле `NUMBER OR NAME`.
   Оба пути равноправны — на iPhone камера иногда капризничает
2. **Сканер.** Видоискатель с уголками-паутинками, подпись `AIM AT UPC ON THE BOX BOTTOM`,
   пиксельная анимация «сканирую». Фолбэк-кнопка `TYPE INSTEAD`
3. **Подтверждение** (обязательный шаг — эксклюзивы иногда делят один штрих-код):
   плашка в стиле «SIGHTING IN YOUR DIRECT VICINITY» с глазами Спайди:
   `IS IT THIS ONE?` + карточка фигурки + горизонтальный ряд вариантов
   (Common / Chase / GITD / Metallic). Кнопки `CONFIRM` (янтарная) / `NOT THIS ONE`
4. **Детали.** Место (страна+город, по умолчанию — последнее использованное), дата
   (по умолчанию сегодня), статус, заметка-история (опционально, можно `SKIP FOR NOW`)
5. **Успех.** Полноэкранный кадр `SIGHTING CONFIRMED!` — паучок прыгает в ячейку коллекции,
   LCD-счётчик тикает `12 → 13`. Кнопки `ADD ANOTHER` / `VIEW IT`

Фото фигурки НЕ загружается никогда — бокс-арт подтягивается из справочника автоматически.

### 6.3 Catalog

Таблица-список справочника: поиск, фильтр `NEEDS REVIEW`, инлайн-редактирование,
кнопка `+ ADD FIGURE` для фигурок, которых нет в базе.

## 7. Ключевые компоненты (собрать как отдельную страницу-витрину)

- **FigureCard** — пиксельная рамка, бокс-арт, янтарный номер-бейдж, имя, флаг; состояния:
  owned / wanted / not-mine-anymore / new-sighting (со «звёздочкой» как синие маркеры в референсе)
- **VerdictStamp** — OWNED (зелёный) / NOT OWNED (коралловый), большой, «проштампованный»
- **LCDCounter** — тёмно-зелёный экран, светящиеся цифры, лёгкий скан-лайн
- **PixelButton** — янтарная CTA / зелёная secondary / коралловая danger; нажатие —
  сдвиг на 2px вниз («кнопка утоплена»)
- **TickerBar** — бегущая строка на тёмном LCD
- **ToothedBanner** — коралловая плашка с зубчиками (алерты, заголовки разделов)
- **WebRadar** — паутина-прогресс
- **MapMarker** — пиксельный паук в круглой рамке (зелёный/красный/серый)
- **ScannerOverlay** — видоискатель с уголками-паутинками
- **Mascot** — маленький пиксельный паучок (СВОЙ спрайт, не из фильма)

## 9. Адаптивность

**Mobile (базовый, проектировать первым):**

- Один столбец, грид карточек 2 колонки, safe-area снизу
- Все действия — в зоне большого пальца; тап-таргеты ≥ 44px
- Поиск и «Добавить» (в админке) — прилипшие кнопки
- Пиксельные рамки тоньше, «корпус гаджета» — деликатный, контент важнее декора

**Desktop:**

- Метафора «гаджет на столе»: контент в центре max-width ~1100px, вокруг — паспарту
  `--blue-bright` с лёгкой пиксельной текстурой; рамка-корпус становится толще и наряднее
- Грид 4–5 колонок, карта и радар — крупнее, ticker во всю ширину
- Hover-состояния: карточка «приподнимается» на 2px, кнопки подсвечиваются

**Доступность:** контраст текста на плашках проверить (чёрный на янтарном, кремовый на
синем — ок; кремовый на коралловом — только жирный/крупный). Пиксельный шрифт — минимум
10–11px и только для коротких строк. Уважать prefers-reduced-motion: анимации маскота
и тикер отключаемы.

## 10. Микрокопия — тон гаджета

Коротко, по-гиковски, от лица устройства: `SIGHTING CONFIRMED!`, `63 SPIDERS STILL OUT
THERE`, `SCANNING…`, `NOT THIS ONE?`, `ALREADY IN THE VAULT` (для дубликата при добавлении),
`GIFT IDEA UNLOCKED`. Ошибки — честные и с характером: `BARCODE NOT FOUND. TYPE THE NUMBER?`

## 11. Чего избегать

- Глянцевого «маркетплейс»-стиля: это личная полка, а не магазин
- Прямых копий кадров фильма, логотипов Marvel/Sony, постерного леттеринга
- Пиксельного шрифта в длинных текстах
- Перегруза декором на мобиле: рамки и маскот не должны съедать место у контента
- Светлой темы — мир гаджета тёмный, это фича
