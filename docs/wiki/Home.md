# Spidey Shelf Wiki

Personal Funko Pop (Spider-Man) collection tracker. Public showcase + gift-check search,
single-admin quick-add with barcode scanning. Mobile-first, pixel-gadget aesthetic.

> Source of truth for these pages is `docs/wiki/` in the main repo — edit via PR;
> this wiki is auto-synced on merge to `main`.

- [[Data-Model]] — tables, keys, views
- [[Design-System]] — tokens, typography, components
- [[Environment]] — env vars, setup runbook, manual one-time steps
- [[Decisions]] — ADR log (why the stack is what it is)
